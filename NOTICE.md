# Notice on terminology data

The [MIT license](LICENSE) applies to the software code in this repository only.

fhir-codebridge is designed to work with clinical terminology data from various
sources, and that data carries its own separate licensing requirements:

| Vocabulary | Requirement |
|---|---|
| SNOMED-CT | Requires a UMLS license — see [SNOMED_LICENSE.md](SNOMED_LICENSE.md) |
| LOINC | Free registration at [loinc.org](https://loinc.org) |
| ICD-10-CM | Public domain (CDC / CMS) |
| CDT | Copyright American Dental Association, used under fair use for interoperability |
| RxNorm | Public domain (NLM / NIH) |

Users are responsible for ensuring they have appropriate licenses for any
terminology data they load into the system.
